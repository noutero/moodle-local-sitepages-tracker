# Site pages for Moodle — public issue tracker

This repository is the **public bug and support tracker** for **Site pages** (`local_sitepages`).

Plugin **source code is not published here**. Download Site pages from Moodle Marketplace (free), or get it bundled with paid **PageTiler**.

## Related

| Plugin | Tracker |
|--------|---------|
| Site pages (`local_sitepages`) | This repo |
| PageTiler (`mod_pagetiler`) | [pagetiler-moodle-tracker](https://github.com/noutero/pagetiler-moodle-tracker/issues) |

## Demo and docs

- Demo: https://pagetiler.ivent.pl
- Admin guide: https://pagetiler.ivent.pl/local/sitepages/view.php?slug=docs

## How to report an issue

1. Open a [new issue](https://github.com/noutero/moodle-local-sitepages-tracker/issues/new/choose).
2. Include Moodle version, theme, and steps to reproduce (pretty URLs, homepage override, My courses, etc.).

## Security

Please do **not** open public issues for security vulnerabilities. Contact the author via the Marketplace listing support channel.
